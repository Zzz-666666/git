# 晚灯 2.2 独立版

这套程序可在普通 Node.js 服务器运行，注册、登录、文字、头像、语音、好友、关注、备注和私信均不调用 GPT，也不需要 GPT 账号。默认进入自己的空间，支持文字和最长 120 秒、最大 5 MB 的语音。

当前状态：独立版已构建并通过本机 PostgreSQL 引擎与 SQLite 模式上的完整接口验证。用户已确认 2.2.0 安卓版可开始录音、试听和发送。尚未创建实际 Render / Supabase 资源，也没有迁移原网站数据；云端部署需在连接平台后进一步验证。

## 免费部署：Render + Supabase

核对日期：2026-10-16。两个平台都选择 Free，使用平台附送网址，无需先购买域名。免费额度或政策可能变化，创建时以平台显示为准。此方案可作为小规模体验服务；不承诺永久免费或持续在线。手机所在网络能否直接访问新网址，需要上线后实测。

- Render Free：15 分钟无访问后休眠，首次唤醒通常约一分钟；每个工作区每月 750 个免费实例小时。本机文件会在休眠、重启或重新部署时丢失，因此本版本不在 Render 本地保存账号或语音。
- Supabase Free：500 MB 数据库、1 GB 文件存储、5 GB 普通出站流量；连续一周不活跃的项目可能暂停，需要所有者在控制台恢复。免费档不含自动数据库备份。程序休眠不会清空 Supabase 中的数据，但需要自己备份，平台没有永久保留保证。
- 请勿创建 Render Free Postgres 来存正式账号：它会在创建 30 天后到期。本版本使用 Supabase 的数据库。

官方说明：[Render](https://render.com/docs/free)、[Supabase](https://supabase.com/pricing)。

## 开通步骤

1. 注册 Supabase 和 Render；如果希望由 Codex 继续操作，连接这两个平台的插件。Render 通常还需要连接存放本源码的 Git 仓库，建议私有仓库。
2. 在 Supabase 创建 Free 项目，优先选新加坡。创建强数据库密码并保存在密码管理器，不要发在聊天里。
3. 在 Storage 新建 `wandeng-private` 桶，Public 保持关闭。整个桶都不添加公开读取或匿名上传策略。应用服务会检查桶为私有，读取时先检查晚灯账号和内容的可见范围。
4. 在项目 Connect 页面复制 **Session pooler、端口 5432** 的 PostgreSQL 连接串。将真实密码填入连接串并按 URL 规则编码特殊字符。不要用仅 IPv6 的直连地址。数据库连接强制验证 TLS 证书，如项目需要自有 CA，可在 Render 额外设置 `DATABASE_CA` 为官方证书内容，不能关闭证书验证。
5. 在 Supabase API 设置获取项目 URL 和 legacy `service_role` 服务端密钥。密钥只填入 Render 的加密环境变量，不写入源码、网页、安装包或公开仓库。
6. 把本源码上传到自己的 Git 仓库。在 Render 新建 Blueprint，选择仓库中的 `render.yaml`。确认 Web Service 计划为 **Free**。该配置不会创建付费数据库或磁盘。
7. 按界面提示填写 `DATABASE_URL`、`SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`。`SUPABASE_BUCKET` 默认为 `wandeng-private`。程序自动使用 Render 分配的 HTTPS 网址，不需要事先购买域名。
8. 等部署成功后，在手机上打开新网址，测试注册、退出再登录、录音发送、播放和私密内容。休眠后再打开，确认数据仍在。
9. 核对新网址可达后，才能把原网站最新数据迁移进去，并把安卓安装包默认网址换到新服务。当前 2.2.0 APK 仍连接原网址，不能把本地源码包当作已上线的独立服务器。

## 本机开发和验证

需要 Node.js 24.19 或更新的兼容版本、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm run build
node dist/server.mjs
```

本机默认监听 `127.0.0.1:8788`，数据为 SQLite 和文件，位于 `dist/data`（可通过 `WANDE_DATA_DIR` 改到持久目录）。云部署必须设置 `WANDE_STORAGE=cloud`，否则在 Render 上拒绝启动，避免误把数据保存到临时磁盘。

云端表保存在独立的 `wandeng` schema 中，初始化不修改现有 public 表。应用表启用 RLS，并撤销 PUBLIC、anon、authenticated 的权限；业务访问统一经过服务端晚灯账号鉴权。密码继续使用兼容旧版的 PBKDF2-SHA256、600000 次迭代，重名账号自动追加 4–6 位数字。

```sh
# 云存储协议与私有桶检查 + 构建本机 PostgreSQL 测试服务器
pnpm run check
# 在一个终端启动测试服务（PowerShell 用 $env:PORT='8790' 等设置环境变量）
PORT=8790 WANDE_TRUST_PROXY=1 node .runtime/cloud-test-server.mjs
# 另一个终端执行完整接口测试；只允许 127.0.0.1
node verify-api.mjs http://127.0.0.1:8790
```

测试服务器使用本机 PGlite PostgreSQL 引擎和内存文件桶，不会访问真实 Supabase 或原网站。`WANDE_TRUST_PROXY=1` 只用于本机测试和已限定代理 IP 的部署；Render 环境由服务端单独处理其转发信息。

## 迁移与备份

迁移需要原服务的最新完整导出与对应头像、语音文件；旧的临时体验数据不能覆盖当前账号。不得将私人导出、恢复码、真实 `.env` 或签名密钥放进源码仓库。

`node dist/import-data.mjs 私有导出.json` 可把已授权的数据导入空库，表内容在一个事务中写入，云端拒绝覆盖已有数据。旧版未绑定账号的空间可以生成一次性迁移码，保存在私有 `data/旧空间迁移码.txt`。已有晚灯账号的密码哈希兼容，不需要重设密码；登录会话不迁移，迁移后需要重新登录。导入工具不搬运头像/语音二进制，文件迁移需要另行完成。

请定期使用 Supabase 官方数据库导出方式保存备份，并单独备份私有存储桶文件。免费版没有自动备份，数据库备份不包含 Storage 文件；导出文件应加密并留在个人存储中。不要用定时请求规避免费平台的休眠政策。

## 安卓录音

2.2.0 的“语音”通过标准文件选择回调进入 Android MediaRecorder 录音窗口，使用 AAC / M4A。只在前台、用户点击开始后录音；退到后台会取消；停止后返回网页预览，用户点击发送才会上传。麦克风权限被拒绝时提供系统设置入口。临时录音只位于应用私有缓存，内容提供者不对其他应用公开。网页仍支持浏览器录音，并提供选择音频文件的备用入口。

本版本已通过编译、签名与接口测试，用户也已确认原服务上的安卓录音、试听和发送正常。新服务器仍需在用户手机上测试访问、登录和语音播放。
